Output

no other attributes allowed

Structural extraction of every numeric financial SCHEDULE (account x fiscal-year pivot) printed in a U.S. Budget Appendix page. Each account prints standardized schedules — 'Program and Financing', 'Object Classification', and 'Employment Summary' — each a small table with an Identification code and the fixed fiscal-year columns. Capture each schedule as a generic pivot: the fiscal-year column headers once, then one row per printed line (line code + description) with a positional value array. Ignore the surrounding narrative appropriations-language paragraphs — they are NOT tables.

AttributeTypeDescription
tablesrequiredlist of ScheduleOne entry per printed financial SCHEDULE on the page. A schedule is a captioned numeric block: its caption is one of 'Program and Financing (in millions of dollars)', 'Object Classification (in millions of dollars)', or 'Employment Summary', and it begins with an 'Identification code ...' header row. Include every such schedule. Do NOT emit the narrative paragraphs, the account name headings, or '...—Continued' banners as tables.

Schedule

Used by Output › tables

AttributeTypeDescription
table_numberrequiredstringComposite identity of the schedule: the printed Identification code, then ' | ', then the schedule kind. E.g. '002-0477-0-1-801 | Object Classification'. The Identification code is the value printed after the words 'Identification code' in the schedule's header row (format like '002-0477-0-1-801'). The schedule kind is exactly one of 'Program and Financing', 'Object Classification', 'Employment Summary' (drop the '(in millions of dollars)' suffix). Do NOT confuse the Identification code with a line code (the 4-digit codes like 1100, 3000 inside the rows). Use ASCII hyphens '-' in the identification code (normalize any source en-dash to '-'). The schedule-kind suffix is Title Case exactly as listed.
table_titlerequiredstringThe schedule kind verbatim: one of 'Program and Financing', 'Object Classification', 'Employment Summary'. Do NOT include the '(in millions of dollars)' suffix or the account name.
column_headersrequiredlist of stringThe fiscal-year column headers printed at the top of the schedule, left to right, verbatim. For FY2024 Budget Appendix schedules these are exactly ['2022 actual', '2023 est.', '2024 est.']. EXCLUDE the leftmost stub column (the line code + description) — it is the row_label, never a value column. The length MUST equal the number of value cells in every row.
rowsrequiredlist of ScheduleRowOne entry per printed data line of the schedule, top to bottom. A data line has a line code (e.g. '0001', '1100', '3000', '11.1', '99.9', '1001') and/or a description and at least one numeric value. EXCLUDE pure section-heading lines that carry NO values (e.g. 'Direct obligations:', 'Budgetary resources:', 'Unpaid obligations:', 'Appropriations, discretionary:', 'Budget authority and outlays, net:', 'Outlays, gross:', 'Memorandum (non-add) entries:').

ScheduleRow

Used by Schedule › rows

AttributeTypeDescription
row_labelrequiredstringThe stub-cell text for this line, verbatim: the printed line code followed by a single space and the description, with trailing dot-leaders removed (e.g. '1100 Appropriation'; '3000 Unpaid obligations, brought forward, Oct 1'; '99.9 Total new obligations, unexpired accounts'; '1001 Direct civilian full-time equivalent employment'). Keep the leading numeric line code as part of the label — it is the identity_key for the row within its schedule. If a line truly has no printed code, use the description alone.
valuesrequiredlist of string or nullThe fiscal-year cell values for this line, left to right, one entry per column_headers entry (same length, same order). Each value is the printed number verbatim as a string. Negative values are printed with a leading minus and MUST keep the sign (e.g. '-4', '-553'). Do NOT add thousands separators that are not printed. Use JSON null for a cell printed blank/empty (these schedules often leave a cell blank, shown as dots or nothing) — do NOT invent a 0.
